# Neno-Dialer-Landingpage

Official enterprise landing page for **Neno Dialer** by **Neno Technology**, built with React 19, Vite, and Tailwind CSS adhering strictly to the **Sahara Warm Minimalist** design system (`DESIGN.md`).

## 🚀 Features

- **WebRTC Active Command Center**: Interactive live call simulator with dual-channel speech energy visualizers, call controls, live notes, tag taxonomies, and supervisor whisper coaching.
- **Automated Call Distribution (ACD)**: 5-step routing flowchart and real-time agent availability matrix.
- **Inbound & Outbound Calling Engines**: Predictive, Progressive, and Preview dialing architecture cards.
- **Call Quality & Audit Scorecards**: Interactive QA evaluation checklist with 30-day trajectory analytics.
- **Workforce Operations**: Live telecaller roster tracking with work time classification progress metrics.
- **Interactive Industry Switcher**: Custom workflows for 8 communication-heavy verticals (Insurance, Automobile, Healthcare, BPO, Banking, FMCG, Telecom, Real Estate).
- **Enterprise Demo Booking Modal**: Form handling and interactive seat count selector.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Google Material Symbols
- **Typography**: EB Garamond (Serif Headlines) & Manrope (Sans-Serif Body)
- **Design System**: Sahara Warm Minimalism (`#c2652a` Burnt Sienna, `#faf5ee` Warm Linen)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build
```
